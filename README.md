人格测试告诉你：你是 INTJ，或者你是九型中的某一型。<br>
大模型告诉你：你是一个很有深度、但有时会对自己太苛刻的人。<br>

这个工具只做一件事：**拿你自己和五年前的你比。**
对照组是你本人，不是任何陌生人。

## 🎯 它凭什么不是算命

1948 年，福勒给一群学生发了同一份「个性分析」，内容抄自报纸星座专栏。
学生给它的准确度打分是 **4.26 / 5**。

**一个大模型可以免费、即时、无限地生成这种句子。**
所以这个项目一大半的工程量，花在了怎么**不生成**它们上。

### 出报告前要过八道闸

| 闸 | 干什么 |
|---|---|
| **反向测试** | 把每条判断反过来写，反过来也成立的，删 |
| **八成人测试** | 对随便一个中国成年人也成立的，删 |
| **证据回指** | 挂不上具体数字或三条原话的，删 |
| **级别对齐** | 弱证据不许写成陈述句，只能写成问句 |
| **迎合检查** | 全文没有一处读者想反驳的，回去重写 |
| **归因检查** | 不许把收入、疾病、歧视写成你的性格问题 |
| **危机检查** | 命中自伤或暴力，求助信息放最前面，只呈现不解读 |
| **构成披露** | 某类场景超过 60% 要挂警告 |

**删减量少于 25% 说明没认真跑。** 细节见 [`references/anti-barnum.md`](references/anti-barnum.md)。

**为什么必须是「删」而不是「叮嘱模型别这样」**：ELEPHANT 基准（Cheng 等，2025）试过——
在提示词里加「不要迎合」之后，模型的含糊和回避确实减少了，
**但认同用户的比例一点没降**。它会照着你的话不再打太极，然后接着夸你。
所以闸必须开在成品上，不能开在指令里。

### 收尾不问「准不准」

1984 年 Harris 与 Greene 发现：巴纳姆式的通用描述会被评为**比真实的个人化描述还准**，
但同一批人同时把它评为**最不独特**。「准不准」这个问题问不出真东西。

这个工具的报告结尾问的是另一个问题：

> **这里面有哪几条，是只有你这样，而不是大部分人都这样？**

一条都挑不出来 → 这份报告是星座运势，请丢掉它。

### 每句话都要挂一个证据等级

| 级别 | 是什么 | 允许怎么说 |
|---|---|---|
| **甲** | 数出来的，不是推断 | 直接陈述 |
| **乙** | 强证据，或跨年自比 | 「相比三年前的你」 |
| **丙** | 弱证据 | 必须并列给两种解释 |
| **丁** | 纯解释框架 | **只能是问句** |

这个分级不是拍脑袋定的，是照着实际效应量定的：

- **从用词推断年龄段：r ≈ 0.84**（Schwartz 等，2013，7 亿词）→ 「人生阶段」这一章可以写得笃定
- **从用词推断人格：r ≈ 0.31–0.42** → 只解释了 18% 的差异，所以那一章**只给可能性，不给结论**
- **第一人称单数与抑郁：r = .10**（Tackman 等，2019，N=4,754）→ 接近检测极限，必须给反面解释

**市面上的同类产品把这个关系做反了**：大讲人格类型，不碰人生阶段。

### 而且它测的根本不是「你」

有一项合并了 85,724 人的研究（Koutsoumpis 等，2022，Psychological Bulletin）
把两件事分开算了：

| 比的是什么 | 相关系数 | 解释了多少差异 |
|---|---|---|
| 用词 ↔ 你**自己报告**的性格 | .08–.14 | **5.1%** |
| 用词 ↔ **别人看你**觉得你是什么样 | .18–.39 | **38.5%** |

**同一套方法，预测「你给人的印象」比预测「你实际是什么样」准将近七倍。**

一份从文字生成的人格描述，**本质上是一台印象测量仪，穿着人格测量仪的衣服**。
所以这个工具的第 4 章不叫「你是什么样的人」，
它叫**「你的文字让人觉得你是什么样的人」**。这个区别是实打实的，不是文字游戏。

### 模型稳定 ≠ 模型对

Marengo 等人 2025 年让 GPT-4o 和 Gemini 各读同一批人两年的帖子，各跑十遍：

| 谁和谁比 | 相关系数 |
|---|---|
| 两个不同的大模型读同一份文本 | **ρ = .53–.78** |
| **模型的判断 ↔ 这个人自己的问卷** | **ρ = .13–.23** |

**模型之间彼此同意的程度，是它们和当事人同意程度的三到五倍。**
它们收敛到的不是这个人，是一个共同的语言学假象。

另一项研究（Zhu 等，2025）更直白：重复跑同一份文本，模型自我一致性 ICC = 0.86–1.00，
而与真实人格的最高相关只有 0.27。**模型极其稳定，而且几乎全错——
而稳定在用户眼里读作「有把握」。**

完整的数字与出处见 [`references/method.md`](references/method.md)。

### 最重要的一条：你是自己的对照组

上面那些效应量都是「拿你和别人比」。这个工具主要做的是**拿今天的你和五年前的你比**。

遗传、家庭、教育、地域、性格基线——所有混杂因素在纵向比较里自动抵消，因为对照组就是你本人。

> **能写成「你变了多少」的，绝不写成「你是什么样的人」。**

## 📥 怎么拿到你的数据

> **⚠️ 2026 年，微信导出这条路基本被封死了。**
> 腾讯从 1 月起用 DMCA 清掉了整个生态——一次点名 4,195 个仓库，
> PyWxDump（9.7k★）、留痕 WeChatMsg（42k★）、chatlog（9.2k★）的作者**自己删了库**。
> 他们的法律主张是：加密数据库本身受版权保护，所以**即使导出你自己发的消息也算规避**。

微信是这个 skill 的主场景，但它**不把命押在微信上**：分析的是**你自己写下的字**，
来源可以混用（把多份 `raw.jsonl` 拼接即可）。

| 顺序 | 来源 | 命令 | 说明 |
|---|---|---|---|
| 1 | **微信 · iPhone 未加密备份** | `--source wechatexporter` | **唯一还活着的稳路**。WechatExporter（8.4k★，GPL-2）走备份解析，不碰内存不碰密钥 |
| 2 | 微信 · chatlog 本地接口 | `--source chatlog` | 仅限已有旧环境：Mac 上要关 SIP，且只支持微信 < 4.0.3.80 |
| 3 | Mac 的「信息」 | `--source imessage` | 本地 SQLite 没加密，苹果允许你读。可作补充语料 |
| 4 | Telegram / WhatsApp | `--source telegram` | 官方导出，完全正当 |
| 5 | **你写过的任何文字** | `--source plain` | 日记、笔记、博客、发件箱——没有聊天记录也能跑 |

**一个能让你白忙一场的坑**：chatlog 的 CSV 导出**没有**「谁说的」这个字段，
必须用 `format=json` 拿 `isSelf`；而微信 4.x 上这个字段是推断的（源码自己标了不准），
所以适配器默认用 `sender` 交叉校验。macOS 微信 3.x 的极性和 Windows 还是**反的**。

完整地图见 [`references/get-your-data.md`](references/get-your-data.md)。

## 🔒 你的数据去哪了

| 东西 | 去哪 |
|---|---|
| 原始聊天记录 | **只在本机**，一步都不上传 |
| 别人说的话 | **第一步就丢弃**，一个字不进后续流程 |
| 联系人真名 | 脱敏成 `人001-a3f2`，对照表权限 600，写进 `.gitignore` |
| 手机号 / 身份证 / 卡号 / 邮箱 / 门牌 | 抽样时自动隐去 |
| 统计数字 + 几百句抽样原话 | **会经过模型 API** —— 这一点不含糊其辞 |

`work/` 目录会自动生成一份 `.gitignore` 把自己整个挡在版本控制之外。

**不支持分析别人。** 分析自己和分析别人在法律与伦理上是两件事，
2026 年那一波「蒸馏别人」的项目已经引来过人格权方面的公开质疑。这条线不打算越过。

## 🪞 一百面镜子

一百位心理学家、哲学家、教育家。**不是拿来引用装点的，是一百把能架在语料上的镜子。**

每一条都长这样（这是真实的一条，不是示意）：

> ### 096 · 保罗·弗莱雷 Paulo Freire
> - **一句话** 觉醒不是心情变好，是看清处境里哪些事是被别人安排的，并且开始能动它一下。
> - **诊断问句** 你说的「应该」是谁的应该？写下最近三条自我要求，各写出它最早从谁那里听来。
> - **语料信号** 「没办法 / 就这样了」对「我打算改 / 我去问一下 / 我拒绝了」的比值。
> - **命中读法** 强命中＝比值高于 5:1，而这人能把那套要求的理由背得很熟——
>   把压迫者的道理背得最顺的，常是被压的那个。
> - **处方** 七天，每天写一条今天让你不舒服的具体安排，后接三栏：规则谁定的、
>   你为它付了什么、你能做的最小一件事。第七天挑一条真去做。
> - **反对意见** 最大的滥用是反过来用：拿「你还没觉醒」指责一个已经在硬撑的人，
>   等于把结构性问题退回个人品格。

**「反对意见」这一栏一条都不许省。** 它是这个项目和成功学的分界线。
里面写的是真的：习得性无助被塞利格曼本人 2016 年推翻、
「3:1 积极率」2013 年被 American Psychologist 正式撤稿、
成长型思维在大样本复现里效应量很小、多重迷走理论的解剖学前提受到实质质疑。

## 🔬 怎么跑的

```
你的聊天记录
    ↓  adapters.py      六种来源 → 统一格式
    ↓  extract_me.py    只留自己的话 · 脱敏 · 清噪声       ← 别人的话在这里被丢光
    ↓  stats.py         代词 / 比值 / 逐年 / 关系差异      ← 本地算，不出机器
    ↓  sample.py        分层抽样几百句 · 敏感信息隐去
    ↓  模型 + 100 面镜子 + method.md 的证据分级
    ↓  anti-barnum.md 八道闸                              ← 删掉 25% 以上
一份会自己攻击自己的报告
```

报告结构（[完整模板](references/report-template.md)）：

```
0 · 这份报告是怎么来的     语料构成 · 时间线上的空洞 · 免责
1 · 镜子                   全是计数，没有一句解释
2 · 编年                   你是什么时候变的 · 三个转折点
3 · 你在哪个阶段           三把尺子量同一个位置，分歧原样写出来
4 · 性格                   只给可能性 · 每条附「能推翻它的证据」
5 · 状态                   只写最近 12 个月，和去年比
6 · 会诊                   8–12 位思想家，各出一问一方一反对
7 · 九十天                 三件事 + 一件不要做的事
8 · 这份报告可能错在哪      证据最薄的三条 · 抽样偏差 · 词典误判
```

## 🧭 和别的项目什么关系

这个方向上已经很热闹了，但每一类都只拿走了一块：

| 类别 | 代表 | 拿走了什么 | 剩下什么没做 |
|---|---|---|---|
| **蒸馏类** | 女娲.skill (31k★) · distilly (24k★) · 自己.skill (3.3k★) | 把聊天记录变成一个会模仿你的 AI 人格 | **输出是给模型看的，不是给你看的** |
| **年度报告类** | 留痕 WeChatMsg (42k★) · echotrace (3.8k★) | 统计与图表 | 停在「你发了 47,000 条，高峰 23 点」，**没有解释层** |
| **访谈类** | Satori · elicitation · life-audit | 用提问了解你 | **重新掉回自我报告的偏差**——你告诉它的，已经是你美化过的 |

这一个只做那块没人做的：**你自己的语料 → 一份给你读的报告 → 你能动手的三件事**，
并且全程标注自己有多不确定。

顺带一提：Anthropic 官方 skills 仓库（171k★）里，这个方向**一个都没有**；
而他们自己 2026 年 4 月的研究说，**6% 的 claude.ai 对话是在寻求个人指导**，
其中**关系类对话里模型迎合用户的比例高达 25%**。
需求是真的，陷阱也是真的。

## 🚫 它不做什么

- **不做诊断**。不给人格类型、不给四个字母、不给依恋标签——这些东西的信度不足以印给一个人看。
- **不替你宣布你「真正想要」的是什么。** 这是这类报告最傲慢的一句。
- **不把结构性困境写成性格问题。** 聊天记录里的疲惫，可能是心态问题，也可能是**一周工作八十小时**。默认后者。
- **不建议任何人「少抱怨」。** 抱怨往往是唯一还在流动的出口。
- **不把痛苦写成美的东西。** 「你的敏感是一种天赋」这类句子一律删除。

### 五个已知偏差，报告里会自己承认

1. **你的用词里混着对方的用词**——关系近的两个人虚词用法会互相靠拢，所以「你在某人面前特别爱道歉」也可能是他爱道歉、你跟上了
2. **语境坍塌**——你在工作群和家人群里是两个人，这是正常社会功能
3. **语料里的沉默不等于生活里的沉默**——亲密的话常发生在电话里、见面时
4. **幸存者偏差**——删掉的聊天、退出的群，往往正是最重要的部分
5. **词典是死的**——它认得「累」，认不得「我最近像块抹布」

> **这不是临床评估。** 持续两周以上的情绪低落、睡眠障碍或功能受损，请找专业人士。
