# 思想家条目格式规范

这 100 位不是用来引用装点的，是 **100 把可以架在语料上的镜子**。
每一条都必须能被一个 agent 直接拿去，对着「用户自己说过的话」做一次判断。

抽象的思想史介绍在这里没有价值。判断标准只有一个：
**一个从没读过这位思想家的 agent，读完这条，能不能对一份聊天语料做出一个可能为假的判断？**

## 条目模板（严格照抄字段名与顺序）

```markdown
### {编号} · {中文名} {外文名}

- **领域** 心理学 / 哲学 / 教育学 —— 二级流派
- **一句话** 用一句大白话说出他最要害的那个洞见。不要用他的术语。
- **要害概念** 三到四个，用 `·` 分隔。术语后面用括号给一句大白话解释。
- **诊断问句** 一句直接问到用户脸上的问题。要具体到能刺痛，不能是「你幸福吗」这种。
- **语料信号** 在「用户自己说过的话」里能观察到什么。必须可操作：具体的句式、词、频率、时间分布、对不同对象的差异。写成一个 agent 能照着找的检索指令。
- **命中读法** 信号出现意味着什么。写清楚强命中与弱命中的差别。
- **处方** 一个七天内做得到的具体动作。有明确的开始条件和完成标志。不要「多关注自己的内心」这种。
- **反对意见** 这把镜子什么时候是错的、会伤人、会被滥用。**这一栏不许省略，也不许敷衍。**
```

## 各栏的硬要求

**一句话** —— 不许出现他本人的术语。「阴影」不行，「你最看不惯别人的那一点，多半是你自己不肯承认的那一面」可以。

**语料信号** —— 这是全篇最重要的一栏，也是最容易写废的一栏。
写废的样子：`表达中透露出的焦虑感`。agent 没法执行。
写对的样子：`统计「应该 / 必须 / 不得不 / 只能」对「我想 / 我要 / 我打算」的比值；比值 > 1.5 且跨年上升为强信号；再看这个比值在对家人说话和对朋友说话时是否分裂`。

信号可以是四类，写的时候标明是哪一类：
- `词频类` —— 某类词的出现率，最好给出可比的基线或比值
- `句式类` —— 特定说话结构（条件句、让步句、自我否定后缀、反问）
- `时间类` —— 分布在一天中的位置、跨年变化、突然中断或爆发
- `关系类` —— 同一个人对不同对象的说法差异（这一类最有力，因为它自带对照组）

**处方** —— 必须能在七天内做完并知道自己做没做到。
写废的样子：`练习活在当下`。
写对的样子：`连续七天，每晚睡前写一句今天你替别人做了决定的事，第八天读一遍这七句，圈出哪几件本来不该你管`。

**反对意见** —— 认真写。这一栏是这个项目和算命的分界线。
真诚地写出：这套说法在什么情况下会把结构性困境（贫穷、疾病、歧视、真实的坏运气）误判成个人问题；什么样的人不该用这把镜子；这位思想家的哪些结论已经被后续研究推翻或大幅削弱（复现失败、样本问题、时代局限）。
已知被削弱的，必须写明。举例：自我损耗、грит/坚毅的效应量、部分依恋类型的稳定性主张、弗洛伊德大部分具体机制。

## 语气

中文，克制，不煽情，不用感叹号。
不写「让我们一起探索内心的旅程」这种句子。
读者是一个正在被这面镜子照的人，他不需要被哄。

## 长度

每条 200–320 字之间。宁可少写一栏的废话，不许把任何一栏写成套话。
